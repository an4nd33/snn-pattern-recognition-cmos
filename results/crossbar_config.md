# Crossbar Array Configuration

| Parameter | Value |
|---------|-------|
| Crossbar Size | 2 × 3 |
| Input Neurons | 2 |
| Output Neurons | 3 |
| Total Synapses | 6 |
| Synapse Type | CMOS memristive STDP |
| Computation Style | Analog, event-driven |

The crossbar array enables parallel weighted summation of synaptic currents
and supports in-memory computation for neuromorphic processing.
